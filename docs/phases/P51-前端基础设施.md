### T3：P51.3 — Radix Dialog 迁移（8 个 modal）

**改动**：

| 文件 | 操作 | 说明 |
|---|---|---|
| `frontend/src/shared/dialog.tsx` | **新增** | 封装 Radix `Dialog` 为项目风格的 `Modal` 组件（`Modal.Root/Trigger/Overlay/Content/Title/Close`），套用现有 `.modal-backdrop`/`.task-modal` CSS |
| `frontend/src/styles.css` | 修改 | 加 Radix `data-state="open/closed"` 动画选择器（fadeIn/fadeOut）；现有 `.modal-backdrop`/`.task-modal` 类保留 |
| 8 个 Dialog 组件（已拆到 pages/）| 修改 | 把手写 `<div className="modal-backdrop">` 替换为 `<Modal.Root open={...}>` + `<Modal.Content>` |

**8 个 Dialog 位置**（拆分后在各自 pages 文件）：
- `pages/workflows.tsx`: `WorkflowCreateDialog`
- `pages/tasks.tsx`: `CreateTaskDialog`、`EditTaskDialog`
- `pages/knowledge.tsx`: `KnowledgeTextDialog`、`KnowledgeCategoryDialog`
- `pages/memory.tsx`: `MemoryEntryDialog`、`MemoryPreferenceDialog`

**关键约束**：
- Radix 自动获得 **focus trap + Esc 关闭 + aria 属性**（现有手写 modal 缺这些）
- 视觉不变：复用现有 `.modal-backdrop`/`.task-modal` CSS 类
- 动画是**新增**（现有 modal 无动画），用 CSS transition
- Radix 的 `open`/`onOpenChange` 与现有 `useState(false)` + 条件渲染的适配：现有模式 `{createOpen && <Dialog onClose={...}/>}` 改为 `<Modal.Root open={createOpen} onOpenChange={setCreateOpen}>`

**Modal 封装参考**：
```tsx
// shared/dialog.tsx
import { Dialog } from "@radix-ui/react-dialog";
import type { ReactNode } from "react";

export const Modal = {
  Root: Dialog.Root,
  Trigger: Dialog.Trigger,
  Overlay: Dialog.Overlay,   // className="modal-backdrop"
  Content: Dialog.Content,    // className="task-modal"
  Title: Dialog.Title,
  Close: Dialog.Close,
};

// 用法（pages 中）：
<Modal.Root open={open} onOpenChange={onClose}>
  <Modal.Overlay className="modal-backdrop" />
  <Modal.Content className="task-modal" aria-labelledby="dialog-title">
    <Modal.Title id="dialog-title">...</Modal.Title>
    ...
  </Modal.Content>
</Modal.Root>
```

## 八、风险与取舍

1. **拆分是纯结构重构，零行为变化**——最大风险是 import 路径写错导致构建失败。缓解：每拆一个页面就跑一次 `tsc -b` 验证。
2. **Radix Dialog 迁移**——7 个 modal 的结构一致（`modal-backdrop`+`task-modal`），映射清晰。但 Radix 的 `open`/`onOpenChange` 与现有 `useState(false)` + 条件渲染的模式需要适配（Radix 控制挂载，不再手动 `{open && <Dialog/>}`）。
3. **token 提取不改值**——只集中管理和命名，tint token 取自现有硬编码值（`#edf2ff`→`--blue-50`），不引入新颜色。
4. **react-router-dom 不删**——虽然只用了 BrowserRouter 包裹，但未来可能用到路由。本包保留，仅标注为待清理。
5. **recharts/sonner 本包只装不用**——具体使用留给后续页面开发包。本包是基础设施，不提前消费。
6. **daily-news.css token 替换**——公开页不受控制台拆分影响，只做 CSS 变量替换（值不变），视觉零变化。
7. **`tsconfig.app.json` 的 `verbatimModuleSyntax: true`**：拆分时所有 type-only import 必须用 `import type { Xxx }`，否则 `tsc -b` 报错。
