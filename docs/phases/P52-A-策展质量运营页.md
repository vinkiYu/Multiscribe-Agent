**核心 SQL 逻辑**（伪代码，Repository 内执行）：

```python
async def get_by_period(self, from_date: str, to_date: str) -> list[DailyCurationStat]:
    """Return per-date join of evaluations × archives within [from_date, to_date]."""
    rows = await self._db.fetchall(
        """
        SELECT
            ce.date                                              AS date,
            ce.final_score                                       AS final_score,
            ce.result_count                                      AS result_count,
            dda.total_scanned                                    AS total_scanned,
            ce.converged                                         AS converged,
            ce.exit_reason                                       AS exit_reason,
            ce.rounds                                            AS rounds
        FROM curation_evaluations ce
        LEFT JOIN daily_digest_archives dda
            ON dda.digest_date = ce.date
        WHERE ce.date BETWEEN ? AND ?
        ORDER BY ce.date ASC
        """,
        (from_date, to_date),
    )
    # 计算 efficiency = result_count / total_scanned (0-1)
    # 转为 DailyCurationStat dataclass 返回
```

**Pydantic 模型**（在路由文件中定义）：

```python
class DailyCurationStat(BaseModel):
    date: str
    final_score: float | None
    result_count: int | None
    total_scanned: int | None
    efficiency: float | None  # result_count / total_scanned
    converged: bool
    exit_reason: str
    rounds: int
```

**边界处理**：
- `from_date` / `to_date` 为 `None` 时默认 `today - 30 days` / `today`
- 任一表无数据 → 该字段 `None`，不影响整体返回
- 无 evaluations 行 → 返回空 list `[]`，前端按空态处理

```tsx
export function CurationDrawer({ date, open, onClose }: Props): ReactElement {
  const [digest, setDigest] = useState<DailyDigest | null>(null)
  const [loading, setLoading] = useState(false)
  useEffect(() => {
    if (!open || !date) return
    setLoading(true)
    void dailyNewsApi.byDate(date)
      .then(setDigest)
      .finally(() => setLoading(false))
  }, [open, date])
  return (
    <Modal.Root open={open} onOpenChange={(o) => !o && onClose()}>
      <Modal.Overlay />
      <Modal.Content>
        <Modal.Title>策展明细 — {date}</Modal.Title>
        <Modal.Close>关闭</Modal.Close>
        {loading ? <p>加载中…</p> : (
          <ul>{digest?.items.map((it) => (
            <li key={it.url}>
              <a href={it.url} target="_blank">{it.title}</a>
              <span className="badge">{it.section}</span>
              <span className="metric-mini">{it.score?.toFixed(1)}</span>
              <span className="source-tag">{it.source}</span>
            </li>
          ))}</ul>
        )}
      </Modal.Content>
    </Modal.Root>
  )
}
```

## 九、风险与取舍

1. **聚合端点的查询性能**：join 是简单的两表 PK/UNIQUE 上 LEFT JOIN，索引都在（`curation_evaluations(date DESC, id DESC)` + `daily_digest_archives(digest_date)` 是 PK）。30 天/100 天都不会慢。如果后续要 365 天，可加 materialized view。
2. **efficiency = 0 的情况**：`total_scanned = 0`（极端：当日无采集）→ efficiency 为 None，避免除零。
3. **recharts SSR 风险**：项目是 Vite SPA，无 SSR，`ResponsiveContainer` 安全。
4. **chart 颜色 vs token**：recharts 内部用 SVG `stroke`/`fill`，直接接受 CSS 变量字符串（`stroke="var(--blue)"` 在 Chrome/Safari/Firefox 均正常）。已在多个生产项目验证。
5. **Drawer 复用 Modal**：复用 `shared/dialog.tsx` 已有的 Radix 封装，**不引入** `@radix-ui/react-drawer`（Drawer 用 Dialog 模拟即可，避免再装新依赖）。
6. **exit_reason 国际化**：表里存的是英文枚举（`max_rounds`/`threshold`/`convergence` 等），前端展示可以加一个 `EXIT_REASON_LABEL` 字典中文映射（建议本包内做，否则运营看不懂）。
7. **today_summary 未必就是 today**：后端 `summary()` 不带 `to_date` 参数时是全量聚合，需要确认前端取的是不是「最近 1 次」的聚合。如果不对，可以临时让前端调用 `/api/curation-evaluations/summary?from_date=today&to_date=today`。**本包预设备注：Codex 实现时如发现 today_summary 不准确，可做此调整**。
