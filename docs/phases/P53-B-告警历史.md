# 执行包：P53-B — 告警历史 + 去重

> **阶段**：新功能（运营能力 — 告警可观测性）
> **目标**：AlertEngine 触发时写 `alert_history` 表持久化；加 5 分钟 cooldown 去重防告警轰炸；暴露 `GET /api/alerts` 端点；前端运营中心新增「告警历史」panel。
> **依赖**：P53-A（依赖 `UpsertStyle` 枚举从 dialect.py 暴露）。
> **预估**：1.5 个工作日。

---

## 一、为什么需要这个包

P53-B 是「新功能」路线：

当前 AlertEngine 把告警「飞书/企微 webhook」发完就丢弃，运营想知道：
1. **昨天发生过什么告警？** —— 答案：查不到，内存里
2. **告警是否风暴过？** —— 答案：每次违规都发一次，无去重
3. **哪些是已知告警哪些是新发？** —— 答案：没法 ack，无法确认

本包解决：持久化 + 去重 + 展示。告警 webhook 仍照常发（飞书/企微通知运维），同时存数据库供前端展示和事后审计。

#### `src/multiscribe_agent/core/alert_history.py`（新建）

```python
from __future__ import annotations

import json
import time
import ulid

from dataclasses import dataclass

from multiscribe_agent.infra.dialect import DialectRepositoryMixin


@dataclass(frozen=True, slots=True)
class AlertRecord:
    id: str
    rule_name: str
    metric: str
    threshold: float
    value: float
    description: str
    fired_at: int
    acknowledged: bool
    acknowledged_by: str | None
    acknowledged_at: int | None
    metadata: dict[str, object]


class AlertHistoryRepository(DialectRepositoryMixin):
    async def record(
        self,
        *,
        rule_name: str,
        metric: str,
        threshold: float,
        value: float,
        description: str,
        fired_at: int,
        metadata: dict[str, object] | None = None,
    ) -> str:
        id_ = ulid.new().str
        # 直接 INSERT，不走 _upsert_sql（无冲突场景）
        sql = """
        INSERT INTO alert_history
            (id, rule_name, metric, threshold, value, description,
             fired_at, acknowledged, acknowledged_by, acknowledged_at, metadata)
        VALUES (?, ?, ?, ?, ?, ?, ?, 0, NULL, NULL, ?)
        """
        await self._execute(sql, (
            id_, rule_name, metric, threshold, value, description,
            fired_at, json.dumps(metadata or {}, ensure_ascii=False),
        ))
        return id_

    async def query_recent(
        self, limit: int = 50, acknowledged: bool | None = None,
    ) -> list[AlertRecord]:
        rows = await self._fetchall(
            "SELECT * FROM alert_history ORDER BY fired_at DESC LIMIT ?",
            (limit,),
        )
        records = [_row_to_alert_record(row) for row in rows]
        if acknowledged is not None:
            records = [r for r in records if r.acknowledged == acknowledged]
        return records

    async def acknowledge(self, id_: str, by: str) -> None:
        now = int(time.time())
        await self._execute(
            "UPDATE alert_history SET acknowledged=1, acknowledged_by=?, acknowledged_at=? WHERE id=?",
            (by, now, id_),
        )


def _row_to_alert_record(row: Mapping[str, object]) -> AlertRecord:
    import json
    return AlertRecord(
        id=str(row["id"]),
        rule_name=str(row["rule_name"]),
        metric=str(row["metric"]),
        threshold=float(row["threshold"]),
        value=float(row["value"]),
        description=str(row["description"]),
        fired_at=int(row["fired_at"]),
        acknowledged=bool(row["acknowledged"]),
        acknowledged_by=row["acknowledged_by"] if row["acknowledged_by"] else None,
        acknowledged_at=int(row["acknowledged_at"]) if row["acknowledged_at"] else None,
        metadata=json.loads(str(row["metadata"])) if row["metadata"] else {},
    )
```

#### `src/multiscribe_agent/observability/alerts.py`

**AlertEngine 新增去重 + 历史持久化**：

```python
DEFAULT_COOLDOWN_SECONDS = 300  # 5 min


class AlertEngine:
    def __init__(self, rules: list[AlertRule] | None = None) -> None:
        self.rules = rules or []
        self._values: dict[str, deque] = {}
        self._callbacks: list[...] = []
        self._tasks: set[...] = set()
        # 新增：
        self._last_fired: dict[str, float] = {}
        self._alert_history = None  # type: AlertHistoryRepository | None
    
    def attach_alert_history(self, repo) -> None:
        """Inject the AlertHistoryRepository. Set by bootstrap.py."""
        self._alert_history = repo
    
    def _schedule_fire(self, rule: AlertRule, metric: str) -> None:
        now = time.monotonic()
        # 去重：5 分钟 cooldown
        last = self._last_fired.get(rule.name)
        if last is not None and (now - last) < DEFAULT_COOLDOWN_SECONDS:
            return
        self._last_fired[rule.name] = now
        # ...原有逻辑...
    
    async def _fire(self, rule: AlertRule, metric: str) -> None:
        samples = self._values.get(metric, deque())
        current_value = samples[-1][1] if samples else 0.0
        # 持久化
        if self._alert_history is not None:
            try:
                await self._alert_history.record(
                    rule_name=rule.name,
                    metric=metric,
                    threshold=rule.threshold,
                    value=current_value,
                    description=rule.description,
                    fired_at=int(time.time()),
                    metadata={"metric_value": current_value},
                )
            except Exception as exc:
                log.warning("alert_history_record_failed", rule=rule.name, error=str(exc))
        # 原有 callbacks
        payload = {"rule": rule.name, "metric": metric, "threshold": rule.threshold,
                   "description": rule.description, "timestamp": int(time.time())}
        for callback in tuple(self._callbacks):
            try:
                await callback(rule.name, payload)
            except (RuntimeError, OSError, ValueError, TypeError):
                continue
```

```python
"""Alert history API."""

from __future__ import annotations

from fastapi import APIRouter, Depends, HTTPException, Query

from multiscribe_agent.api.dependencies import ServiceContext, get_context

router = APIRouter(prefix="/alerts", tags=["alerts"])


@router.get("")
async def list_alerts(
    limit: int = Query(default=50, ge=1, le=200),
    acknowledged: bool | None = Query(default=None),
    context: ServiceContext = Depends(get_context),
) -> list[dict[str, object]]:
    if context.alerts is None or context.alerts._alert_history is None:
        raise HTTPException(status_code=503, detail="alerts unavailable")
    records = await context.alerts._alert_history.query_recent(
        limit=limit, acknowledged=acknowledged,
    )
    return [_record_to_response(r) for r in records]


def _record_to_response(record) -> dict[str, object]:
    return {
        "id": record.id,
        "rule_name": record.rule_name,
        "metric": record.metric,
        "threshold": record.threshold,
        "value": record.value,
        "description": record.description,
        "fired_at": record.fired_at,
        "acknowledged": record.acknowledged,
        "acknowledged_by": record.acknowledged_by,
        "acknowledged_at": record.acknowledged_at,
        "metadata": record.metadata,
    }
```

## 九、风险与取舍

1. **去重粒度**：按 `rule_name` 做 5 分钟 cooldown。同一规则在窗口内只发第一条，剩余样本静默丢弃。
2. **`_alert_history` 注入**：用属性注入（`attach_alert_history`）而非构造函数签名，避免改 AlertEngine 公开 API。
3. **`record()` 失败容错**：持久化失败不应阻断 callback 派发。`_record_to_history` 内 `try/except` 捕获，写 log 但不 raise。
4. **`INSERT_OR_REPLACE` 不可用**：alert_history 用 primary key（随机 ulid）做 INSERT，不会有冲突。直接 `_execute` 不用 `_upsert_sql`。PgDialect 兼容问题规避。
5. **未 ack 告警操作**：前端只展示，ack 端点留后续包（P53-B.2 后续）——本包严格零行为扩展。
6. **acknowledge_by 默认值**：当前没用户系统，写死 `"system"` 或读取 `Settings.admin_user`。Codex 在 review 里确认默认行为，**本包用 `'admin'` 占位**。
7. **ServiceContext 字段类型 `object | None`**：避免 AlertEngine 引入循环 import。用 Protocol duck typing。
8. **告警数据保留期**：本包不实现自动清理，定期任务留 P53-E 文档包处理。
