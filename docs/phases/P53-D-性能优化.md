## 二、任务拆解（3 个子任务）

### T1：P53-D.1 — `save_batch()` 去掉双 COUNT 查询

**文件**：`src/multiscribe_agent/infra/repositories/source_data.py`

**当前**（lines 96-98, 143-146）：

```python
count_before = await self._fetchone("SELECT COUNT(*) AS count FROM source_data")
# ... rows 构建 ...
await self._executemany(upsert_sql, rows)
count_after = await self._fetchone("SELECT COUNT(*) AS count FROM source_data")
return int(count_after["count"]) - int(count_before["count"])
```

**问题**：
- 两次全表 `COUNT(*)` 在大表上慢（source_data 随时间线性增长）
- `COUNT(*)` 是 O(n) 全表扫描，即使有索引也会随数据增长变慢
- `cursor.rowcount` 或 `RETURNING` 已提供插入数，无需再算差值

**修复**：

```python
# 删 count_before 和 count_after
# 用 _db.execute() 的返回值 rowcount（受支持时）
# SQLite: cursor.rowcount 准确返回影响的行数
result = await self._execute(upsert_sql, rows)  # 改用 _execute 而非 _executemany？
# 实际上 _executemany 不返回 rowcount，改为：
inserted = 0
for row in rows:
    result = await self._execute(upsert_sql, row)
    if result is not None and result > 0:
        inserted += 1
return inserted
```

**更好的方案**（保留 batch 性能）：

```python
# 改用 _fetchone 查 INSERT 前的最大 id，再查 INSERT 后的最大 id
# 差值即为新增数（不依赖 COUNT(*)）
max_id_before = await self._fetchone(
    "SELECT MAX(CAST(id AS INTEGER)) AS max_id FROM source_data"
)
# ... batch insert ...
max_id_after = await self._fetchone(
    "SELECT MAX(CAST(id AS INTEGER)) AS max_id FROM source_data"
)
if max_id_before and max_id_after:
    return int(max_id_after["max_id"]) - int(max_id_before["max_id"])
return len(rows)  # fallback
```

> Codex 选择：确认 `_db.execute()` 的返回值行为（SQLite 返回 rowcount 或 None），选用最佳方案。

**验收**：`grep 'COUNT.*FROM source_data' source_data.py` 返回 0。

### T3：P53-D.3 — SQL audit 批量写

**文件**：`src/multiscribe_agent/infra/db.py`

**当前**（lines 216-221）：

```python
async def _executemany(self, statement, parameters_iterable):
    materialized = list(parameters_iterable)
    await connection.executemany(statement, materialized)
    await connection.commit()
    # audit
```

**修复**：

```python
async def _executemany(self, statement, parameters_iterable):
    materialized = list(parameters_iterable)
    await connection.executemany(statement, materialized)
    await connection.commit()
    if self._audit_logger is not None:
        # 批量写 audit：所有 rows 一次 INSERT
        audit_sql = "INSERT INTO sql_audit_log(...) VALUES (?, ?, ?, ?)"
        audit_params = [self._audit_write(statement, p) for p in materialized]
        # 注意：_audit_write 返回的是 (sql, params, ts, duration) tuple
        # 需要改 audit 接口支持 batch
```

**更好的方案**（改 `_audit_write` 为 `_audit_write_batch`）：

```python
async def _audit_write_batch(self, entries: list[AuditEntry]) -> None:
    if not entries:
        return
    sql = "INSERT INTO sql_audit_log (...) VALUES (?, ?, ?, ?)"
    params_list = [e.to_tuple() for e in entries]
    await self._execute(sql, params_list)  # executemany
```
