### T3：Deployment Guide — `docs/deployment/DEPLOYMENT.md`

覆盖：

**1. 环境要求**
- Python 3.12+，Node 20+
- uv 包管理器（后端）、npm（前端）
- SQLite 3.45+ 或 PostgreSQL 16+

**2. 本地开发**
```bash
# 后端
uv sync
cp .env.example .env
# 编辑 .env 填入 API keys

# 前端
cd frontend && npm install && npm run dev

# 启动服务
uv run fastapi dev src/multiscribe_agent/app.py
```

**3. Docker 部署**
```bash
cp .env.example .env
docker compose up -d
```

**4. 生产环境检查清单**
- [ ] API keys 已填入（.env）
- [ ] 数据库选型（SQLite 小规模 / PostgreSQL 大规模）
- [ ] PostgreSQL 连接字符串已配置
- [ ] Redis 已配置（如用分布式调度）
- [ ] 前端构建：`cd frontend && npm run build`，nginx 代理到 `:8000`
- [ ] 日志级别设为 INFO 或 WARNING
- [ ] `MULTISCRIBE_AUDIT_SQL=false`（生产关闭 SQL 审计日志）

**5. PostgreSQL 迁移**
- 参考 `docs/postgres-migration-guide.md`

### T4：Troubleshooting Guide — `docs/troubleshooting/TROUBLESHOOTING.md`

FAQ 格式（问题 → 原因 → 解法）：

| # | 问题 | 原因 | 解法 |
|---|---|---|---|
| 1 | 启动报错 `ModuleNotFoundError: No module named 'uv'` | 未用 uv 环境 | `uv sync` 或 `pip install -e .` |
| 2 | 飞书机器人无消息 | webhook URL 错误 / 未填 | 检查 `FEISHU_WEBHOOK` |
| 3 | LLM 返回空日报 | 全部采集源失败 + 无历史库存 | P31.2 保护抛出 `WorkflowError` |
| 4 |策展未汇聚 | `max_rounds` 太小 / `score_threshold` 太高 | 调高 `max_rounds` 或调低 `score_threshold` |
| 5 | 每日采集 0 条新内容 | RSS 全部 404 / API 限流 | 检查 adapter health 页 |
| 6 | 前端构建失败 `EBADENGINE` | Node 版本不符 | 升级到 20+ |
| 7 | `sqlite3.OperationalError: database is locked` | 并发写入 + SQLite | 换 PostgreSQL 或降低并发 |
| 8 | `asyncpg` 连接失败 | PostgreSQL DSN 格式错 | `postgresql://user:pass@host:5432/db` |
| 9 | 告警未收到 | `alert_targets` 未填 / webhook 失效 | 填 `FEISHU_WEBHOOK` 到 `ALERT_TARGETS` |
| 10 | 日志全是 DEBUG | `MULTISCRIBE_LOG_LEVEL=DEBUG` | 改为 `INFO` |
